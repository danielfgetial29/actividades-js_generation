
# Instrucciones

1. Haz que "¡VEN A BURGER TOWN!" sea una alerta en la que se pueda hacer clic y que diga "ES LA HORA DE LA HAMBURGUESA".
   - Asegúrate de usar el atributo OnClick para esta parte.

2. Cuando alguien haga clic en "¡BURGER TOWN!", un `console.log` debe imprimir "¡Alguien hizo clic en BURGER TOWN!".

3. Añade una imagen de una hamburguesa debajo del titular "¡Una foto de una HAMBURGUESA!".
   - Consejo: Usa Google para ayudarte en esta sección.

4. Cada vez que alguien haga clic en la palabra "¡ARROZ!", el titular "Una foto de una HAMBURGUESA" se vuelve rojo.
